# Configuration reference

`devtrack setup` is the canonical configuration path. It writes a visible, editable environment
file under the DevTrack XDG data home and registers its location. Existing process variables take
precedence. Run `devtrack settings` to see resolved paths and `devtrack doctor` to validate them.

Do not copy old configuration blocks from the wiki. The maintained exhaustive samples are:

- [`devtrack_client/.env_sample`](../../../devtrack_client/.env_sample)
- [`devtrack_server/.env_sample`](../../../devtrack_server/.env_sample)
- [`workspaces.yaml.example`](../../../devtrack_client/workspaces.yaml.example)

## Core runtime

| Variable | Meaning |
|---|---|
| `DEVTRACK_SERVER_MODE` | `managed`, `lightweight`, or `external` |
| `DEVTRACK_SERVER_URL` | External server URL; managed mode resolves its local URL |
| `DEVTRACK_WORKSPACE` | Single repository to observe |
| `WORKSPACES_FILE` | Multi-workspace YAML path |
| `DATA_DIR`, `DATABASE_DIR`, `LOG_DIR`, `PID_DIR` | Runtime paths generated by setup |
| `POSTGRES_URL` | Required by the Python server; never used by the Go database layer |
| `SERVER_EVENT_SYNC_ENABLED` | Opt-in client-event upload to the configured server; default `false` |

## LLM

| Variable | Meaning |
|---|---|
| `LLM_PROVIDER` | Server primary provider: `ollama`, `openai`, `anthropic`, `groq`, or `lmstudio` |
| `OLLAMA_HOST` | Ollama base URL; default `http://localhost:11434` |
| `OLLAMA_MODEL` | Server generation model |
| `GIT_SAGE_PROVIDER` / `GIT_SAGE_DEFAULT_MODEL` | Go-native git-sage provider and model |
| `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GROQ_API_KEY` | Optional cloud credentials |
| `LMSTUDIO_HOST` | Local OpenAI-compatible endpoint |

`OLLAMA_URL` and `LMSTUDIO_URL` are retired names. Use the `*_HOST` variables above.

## Visible timeout defaults

Setup writes `IPC_CONNECT_TIMEOUT_SECS`, `IPC_RETRY_DELAY_MS`, `HTTP_TIMEOUT_SHORT`,
`HTTP_TIMEOUT_SHORT_SECS`, `HTTP_TIMEOUT`, `HTTP_TIMEOUT_LONG`,
`LLM_REQUEST_TIMEOUT_SECS`, the three `PROMPT_TIMEOUT_*` values, and
`SENTIMENT_ANALYSIS_WINDOW_MINUTES`. The Go SQLite concurrency timeout is
`SQLITE_BUSY_TIMEOUT_MS`.

## Secrets and workspace metadata

Keep tokens in the environment file. Keep non-secret routing metadata—workspace path, platform,
organization, project, API URL, user name, ticket pattern, and `skip_issues`—in `workspaces.yaml`.
Never commit real credentials.
