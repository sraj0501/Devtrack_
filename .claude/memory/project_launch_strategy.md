**Wedge:** "DevTrack writes your standup update when you commit." Single feature at launch.

**Positioning (non-negotiable):** No "AI-powered" in tagline (AI trust 29% in 2026). Lead with "runs on your machine, no account required." Local-first is the structural moat. Time-to-value under 60 seconds.

**Platform rollout:** GitHub → GitLab (100 stars) → Azure DevOps → Jira (≥50 requests).

**Channel:** Discord + Twitter → HN Show HN (Tue/Wed 9–11am ET) → console.dev, r/programming, awesome-cli-apps.

**Decision filter:** serves wedge? → protects local-first? → reduces time-to-value? → 50+ requests = build it.
