**Wedge**: "DevTrack writes your standup update when you commit." Single feature at launch; everything else is docs-only until trust is earned.

**Positioning rules (non-negotiable):**
- Never say "AI-powered" in tagline/hero (AI trust at 29% in 2026)
- Never say "platform" or "all-in-one" before user base exists
- Always lead with "runs on your machine, no account required"
- Local-first architecture is the structural moat — never compromise it

**Time-to-value target:** under 60 seconds. No account, no T&C gate, no 12-var `.env` before first standup.

**Platform rollout:** GitHub → GitLab (100 stars) → Azure DevOps (community traction) → Jira (≥50 explicit requests)

**Channel sequence:** Discord + Twitter building-in-public → HN Show HN launch day (Tue/Wed 9–11am ET) → console.dev, r/programming, awesome-cli-apps

**Decision framework (in order):** serves the wedge? → protects local-first moat? → reduces time-to-value? → premature expansion? → who asked (50+ = build it)?
