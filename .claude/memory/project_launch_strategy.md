**Wedge:** "DevTrack writes your standup update when you commit." Single feature at launch; everything else is docs-only until trust is earned.

**Positioning (non-negotiable):** Never say "AI-powered" in tagline (AI trust 29% in 2026). Never say "platform" before user base. Always lead with "runs on your machine, no account required." Local-first is the structural moat.

**Time-to-value:** under 60 seconds. No account, no T&C gate, no 12-var `.env` before first standup.

**Platform rollout:** GitHub → GitLab (100 stars) → Azure DevOps → Jira (≥50 requests).

**Channel:** Discord + Twitter → HN Show HN (Tue/Wed 9–11am ET) → console.dev, r/programming, awesome-cli-apps.

**Decision order:** serves wedge? → protects local-first? → reduces time-to-value? → premature expansion? → 50+ requests = build it.
