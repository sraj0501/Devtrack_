# DevTrack v3.3.0 (development)

This version prepares Git capture and end-of-day reporting for daily use. It removes time
tracking by product-owner decision. Stable v3.2.0 remains the published stable release; pushing
this work to `dev` produces the existing rolling `dev-<commit>` build.

## Changes

- Capture every unseen commit across local branches during bursts and branch switches, retaining
  branch/ticket context and deduplicating shared ancestry.
- Prevent delayed commit enhancement from amending a different HEAD.
- Show server-generated EOD reports and queue history in the CLI. Server actions use `server:<id>`
  for review, avoiding collisions with local numeric IDs.
- Allow pending server actions to be edited or rejected; retain rejected/completed history and
  surface server outages explicitly.
- Remove work-duration inference, timed sessions, corrections, time metrics, and session sync.
  `work start` and `work stop` select and clear ticket context. Legacy duration tables remain
  inert for upgrade compatibility.

## Validation and remaining qualification

Go tests, vet, and Linux build passed. Python: 936 passed, 10 skipped (host live-PostgreSQL lane).
Container acceptance with PostgreSQL captured all 29 expected commits exactly once across bursts,
branch switches, server outage, and restart. On-demand and scheduled reports, queue visibility,
edit/reject, and local/server ID isolation passed.

Packaged-build installation, native Windows acceptance, real integration delivery, AI narrative
quality, daemon-off catch-up, and overnight behavior still need qualification. Sage testing and
the previously deferred learning/platform work remain on hold.
